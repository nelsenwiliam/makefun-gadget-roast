One original line roasting the gadget I use every day — my wireless earbuds, whose left bud always dies mid-sentence while the right one just watches. Pure Python stdlib; `main.py` writes the roast to `/output/entry.txt` (99 characters, one line).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
